## 🛠 Mini Project — DevOps Server Manager (Level-1)

A simple Python script that:

* Stores **server → IP mapping** using a dictionary
* Accepts **server name input** from user
* Checks:

  * If server exists → prints **IP + detected server type**
  * If not → shows **Server not found**
* Lists **all available servers** using loop

This project combines:

* Input handling
* Conditional logic
* Loops
* Lists & dictionaries
* Basic DevOps-style thinking
